01

Installation

Tan_language na Tan_lang_chatbot zinaweza kusakinishwa kupitia Python Package Index (PyPI). Tumia Python 3.12 au version inayoungwa mkono na package.

📚

Library pekee

Kwa developer anayehitaji translation engine, Python API na CLI bila web chatbot.

python -m pip install Tan_language
💬

Web Chatbot

Application kamili yenye backend, frontend, translation engine na Room communication.

python -m pip install Tan_lang_chatbot
Muhimu: Usitumie --no-deps. Pip ita-install dependencies zinazohitajika automatically.

04

Kuunganisha kwa IP Address

Kama chatbot inaendesha kwenye PC moja na unataka simu au PC nyingine kuifikia kupitia Wi-Fi moja, tumia IP Address ya computer inayotumika kama server.

LOCALHOST 127.0.0.1:8000

Inatumika ndani ya computer hiyo hiyo.

NETWORK IP 192.168.1.10:8000

Inaweza kutumiwa na kifaa kingine kwenye network inayoruhusu connection.

Hatua ya 1 — Tafuta IP Address ya PC

Fungua PowerShell au Command Prompt kwenye PC inayoendesha chatbot.

PowerShell 
PS C:\> ipconfig

IPv4 Address . . . . . . . . . . : 192.168.1.10

Tafuta sehemu ya IPv4 Address. Mfano unaweza kuwa 192.168.1.10.

Hatua ya 2 — Anzisha server kwenye network

Server inapaswa kusikiliza network interface badala ya localhost pekee. 

PS C:\my-project> uvicorn main:app --host 0.0.0.0 --port 8000
--host 0.0.0.0: Inafanya server isikilize interfaces za network za computer badala ya kuifunga kwenye 127.0.0.1 pekee.

Hatua ya 3 — Fungua chatbot kwenye simu

Kama PC yako ina IP Address 192.168.1.10 na server iko port 8000, kwenye browser ya simu fungua:

http:// 192.168.1.10:8000

Hatua ya 4 — Tumia Room Code ile ile

Baada ya simu kufungua chatbot, weka Room Code inayotumiwa na PC. Kwa mfano:

PC 192.168.1.10:8000 Room 1234
⇄
PHONE 192.168.1.10:8000 Room 1234
Network: Kwa local-network setup, hakikisha vifaa vinaweza kufikia PC server kupitia network inayotumika. Wi-Fi moja mara nyingi hutumika kwa setup ya ndani, lakini router/access point inaweza kuwa na client isolation au firewall inayozuia vifaa kuwasiliana.
Security note

Usifungue server kwenye public internet bila authentication, access control na security configuration inayofaa. Mfano huu ni wa local-network development/testing.

05

Tan_language Library

Tan_language ni Python library inayotoa translation tools bila kuhitaji kuendesha web server. Python import name ni tll.

translate.py 
from tll import Translator
translator = Translator.from_bundled_dataset('suk')

result = translator.translate( 'mwalimu',
source='suk',
target='sw'
)

print(result)
CLI

tan-language translate --from suk --to sw mwalimu

Inafanya nini?

Inasoma dataset iliyobundled na kutafsiri maneno au sentensi bila backend.

08

Troubleshooting

Pip haisomi command?

Tumia python -m pip badala ya pip. Baada ya installation unaweza kufunga na kufungua Terminal mpya.

Simu haiwezi kufungua 127.0.0.1?

Hii ni kawaida. 127.0.0.1 ni localhost ya kifaa kinachofungua address hiyo. Tumia IP Address ya PC server, kwa mfano 192.168.1.10:8000.

IP Address haifanyi kazi?

Hakikisha server imesikiliza 0.0.0.0, vifaa vinaweza kuwasiliana kwenye network, port 8000 haijazuiwa na firewall, na IP Address ni ya PC inayotumia server.

Vifaa vina IP lakini Room haionyeshi messages?

Hakikisha vifaa vimeingia kwenye Room Code inayofanana na backend yako inaruhusu communication ya Room. Pia hakikisha WebSocket/API endpoints zinazotumiwa na application hazizuiwi.

Port 8000 tayari inatumika?

Funga server nyingine inayotumia port hiyo au tumia port tofauti, kwa mfano: uvicorn main:app --host 0.0.0.0 --port 8001

Windows Firewall inazuia connection?

Angalia Windows Defender Firewall na ruhusu application/server yako kwenye private network ikiwa ni salama kufanya hivyo. Usifungue ports kwa public access bila security configuration.
